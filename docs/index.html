Dependency-free tiny date utilities

Japanese date labels,
made tiny.

日本語の日付表示、相対日付、土日・営業日判定、営業日数の加算・減算を提供する小さな TypeScript ライブラリです。

Try demo Install 
import {
  formatJaDate,
  formatRelativeJaDate,
  nextBusinessDay,
} from "tiny-ja-date"

formatJaDate(new Date(2026, 4, 12))
// "2026年5月12日（火）"

formatRelativeJaDate(
  new Date(2026, 4, 15),
  new Date(2026, 4, 12),
)
// "3日後"

Small scope

日本語UIでよく使う日付ユーティリティだけに絞っています。

営業日ルール

定休日、個別の休業日、臨時営業日を指定できます。

TypeScript ready

依存ゼロ。フロントエンドでもバックエンドでも使えます。

Install

npm からインストールして使えます。

npm install tiny-ja-date

API

formatJaDate

日本語の日付ラベルを返します。

2026年5月12日（火）

formatIsoDate

指定した地域の暦日を YYYY-MM-DD で返します。

2026-05-12

startOfDay

指定した地域での一日の始まりを返します。

Date

addCalendarDays

土日も含めて暦日を前後に数え、移動先の日の始まりを返します。

Date

addCalendarMonths

暦月を前後に移動し、同じ日番号がなければ月末を使います。

Date

countCalendarDays

土日や休業日も含め、基準日から指定日までの暦日数を返します。

number

formatRelativeJaDate

基準日から見た相対日付を日本語で返します。

今日 / 昨日 / 明日 / 3日前

isWeekendJP

土曜日または日曜日か判定します。

true / false

isBusinessDay

指定した日が営業日かを判定します。

true / false

nextBusinessDay

定休日・休業日・臨時営業日の設定を使って、次の営業日を返します。

Date

addBusinessDays

正の数で先へ、負の数で前へ進みます。0 は入力日の始まりを返します。

Date

countBusinessDays

出発日を除き、到着日が営業日なら含めます。逆向きの営業日数は負の値になります。

number

listBusinessDays

出発日と到着日を含む期間内の営業日を、指定した方向順に返します。

Date[]

iterateBusinessDays

期間内の営業日を1件ずつ取り出し、必要な件数で探索を終えられます。

Generator<Date, void, unknown>

createBusinessCalendar

タイムゾーンと休業日ルールを設定し、営業日計算で使い回せます。

BusinessCalendar

CDN

npm公開後は unpkg や jsDelivr から ESM として読み込めます。

https://unpkg.com/tiny-ja-date@1.7.0/dist/index.js 
<script type="module">
  import { formatJaDate } from "https://unpkg.com/tiny-ja-date@1.7.0/dist/index.js"

  console.log(formatJaDate(new Date(2026, 4, 12)))
</script>

Design policy

`tiny-ja-date` は日付ライブラリ全般ではなく、日本語UIでよく使う小さな関数だけを提供します。 

// Outside the scope of tiny-ja-date:
// - Japanese holiday data
// - wareki formatting
// - calendar generation
// - date-fns/dayjs replacement
